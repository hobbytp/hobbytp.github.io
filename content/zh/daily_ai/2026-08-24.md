<h2 id="github-projects">🛠️ 工具与框架</h2>

各位开发者，我是你们的老朋友。今天在 GitHub 巡检时，我锁定了两个极具潜力的“生产力核武器”。

在 AI Agent 走向自主化的当下，如何降低 Token 成本以及如何让 Agent 具备跨模态的“手脚”是目前的工程难点。今天的这两个项目，一个负责“极度脱水”省钱，一个负责“多模态赋能”破局。

以下是今日份的干货汇报：

### 🚀🚀🚀 [oc](https://github.com/only-cli/oc)
- **一句话弄懂**：专为 AI Agent 设计的“网页脱水机”，将臃肿的 HTML 瞬间压缩为极简 CLI 文本流，让 Agent 像读 README 一样读网页。
- **核心卖点**：
    - **Token 降维打击**：传统方案将网页喂给 LLM 动辄消耗数万 Token，`oc` 通过自研的提取算法，将网页信息密度提升数十倍，消耗从 10,000+ Token 骤降至数百，直接砍掉 90% 以上的 API 账单。
    - **Agent 友好型输出**：它不只是简单的 HTML 转 Markdown，而是针对 AI 的理解逻辑进行了结构化优化，去除了导航栏、广告、脚本等干扰噪声，只保留核心语义。
    - **极简集成**：作为 CLI 工具，它可以无缝集成到任何 Agent 的 Tool Call 流程中，是构建自主浏览型 Agent（如 Web Operator）的理想基础设施。
- **热度飙升**：目前 Star 数 223，日均增长 40.7。社区关注点在于其对“长上下文成本”的精准狙击，在 DeepSeek 等长文本模型普及的今天，这种极致的输入端优化是提升 Agent 响应速度和准确率的关键。

---

### 🚀🚀 [mediagen](https://github.com/Cripacx/mediagen)
- **一句话弄懂**：基于 MCP 协议的多模态生成插件，让 Claude Code 等编程 Agent 具备直接生成图片和视频的“创作超能力”。
- **核心卖点**：
    - **统一协议标准**：深度适配 Anthropic 推出的 **MCP (Model Context Protocol)**，这意味着你可以直接在 Claude Code 或 Cursor 中通过自然语言指令生成 UI 素材或演示视频，无需切换窗口。
    - **多模型聚合**：后端聚合了 Gemini、OpenAI 和 Kie AI 等主流生成模型，通过统一的 CLI 接口调用，解决了开发者需要维护多套 API SDK 的痛点。
    - **合规性前瞻**：内置了符合《欧盟 AI 法案》的内容标记机制，这在开源项目中非常罕见，为企业级应用出海提供了合规性保障。
    - **工程闭环**：将“代码编写”与“素材生成”在 IDE 层面打通，极大提升了前端开发和原型设计的迭代效率。
- **热度飙升**：目前 Star 数 54，日均增长 52.8。随着 Claude Code 的爆火，开发者对 MCP 协议插件的需求呈爆发式增长，`mediagen` 作为首批高质量的多模态 MCP 服务，正处于风口之上。
