📐 关于本页：收录标准、CHAOSS 健康度计算口径与数据声明（点击展开）

1. 数据来源：项目池直接同步自作者 GitHub 账号（@{{ $metrics.github_user | default "hobbytp" }}）的公开 Stars 列表及本站在 content/zh/projects/ 撰写的深度解读文章。作者在 GitHub 点 Star 后，定时工作流会自动拉取仓库元数据、增量生成 AI 中文定位并加入研究台。

2. 事实、AI 摘要与作者判断三层分离：客观指标来自 GitHub REST/GraphQL API；一句话中文定位与适用边界若未经人工覆写，则由大模型或结构化规则从仓库元数据提炼；「主力推荐 / 值得试用」等选型标签均由作者人工维护在 data/ai_projects/curated.yaml 中，自动化脚本绝不篡改。

3. CHAOSS 风格健康度公式：综合健康度 = 0.35×活跃度(近期推送与90天提交密度) + 0.25×社区响应(规模与Issue关闭率) + 0.20×发布节奏(近期Release频率) + 0.20×持续合规(开源许可证与维护周期)。点击任意项目详情均可查看各分项原始数值。
